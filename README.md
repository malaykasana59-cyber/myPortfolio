# My Developer Portfolio

A modern, responsive developer portfolio built with **Next.js 16 (App Router)**, **Tailwind CSS v4**, **Framer Motion**, and **Lucide React**.

---

## ✨ Features

- ⚡ **Next.js 16 App Router & Turbopack** - Fast server-side rendering
- 🎨 **Dark Mode Support** - Seamless theme switching
- 🪄 **Smooth Animations** - Scroll-triggered reveals and interactive elements
- ⌨️ **Dynamic Hero Section** - Animated typewriter effect
- 🧰 **Tech Stack Display** - Organized showcase of technologies
- 🚀 **Projects Showcase** - Interactive project cards with filtering
- ⏳ **Timeline** - Experience and education history
- 📬 **Contact Form** - Integrated contact functionality
- 🔍 **SEO Optimized** - Dynamic sitemap and meta tags

---

## 🛠️ Tech Stack

- **Next.js 16** - React framework with App Router
- **Tailwind CSS v4** - Utility-first CSS framework
- **Framer Motion** - Animation library
- **Lucide React** - Icon library
- **next-themes** - Dark mode support
- **Zod** - Schema validation
- **Sonner** - Toast notifications
